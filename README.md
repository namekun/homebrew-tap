# namekun/homebrew-tap

Homebrew casks by namekun.

```sh
brew install --cask namekun/tap/nunsseop
brew install --cask namekun/tap/changmun
```

| Cask | Description |
| --- | --- |
| [nunsseop](Casks/nunsseop.rb) | [Nunsseop](https://github.com/namekun/Nunsseop): turns the MacBook notch into a space for now playing, a file shelf and system HUDs |
| [changmun](Casks/changmun.rb) | [Changmun](https://github.com/namekun/Changmun): a light WebKit browser with a sidebar and an AI that can use it |
